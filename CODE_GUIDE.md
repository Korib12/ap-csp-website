# Echo code guide

A map of the code: where each part lives and what it does, in plain words.
The whole app is one file, `app/index.html` (about 3,700 lines). It's one file on purpose, so the phone can load it once and keep working all night with no server.

**Finding things:** line numbers change as the code changes, so search for the function name instead (Ctrl+F, or Cmd+F on a Mac). In VS Code you can also press Ctrl+Shift+O (Cmd+Shift+O on a Mac) and type a function name to jump straight to it.

## How the file is laid out

| Part | Roughly where | What's there |
|---|---|---|
| `<style>` (CSS) | top, lines 1–600 | Colors, layout, glass cards, animations. The very long lines are photos stored as text (base64), so the app stays one file. Fold or skip them. |
| HTML | lines ~600–1000 | The intro, the four tabs (Tonight, Trends, Reports, Settings), the Help page, the night screen, the accuracy test and doctor-report overlays. |
| JavaScript | lines ~1000 to the end | Everything Echo *does*. The breathing engine is roughly lines 1180–1930. |
| Translations | near the end, one very long line between `/*I18N-START*/` and `/*I18N-END*/` | Generated by `tools/build_i18n.py` from `tools/i18n_strings.py`. Don't edit this line by hand. |

## The breathing engine, step by step

This is the part to understand best, because it's what makes Echo different.

| Step | Function | What it does |
|---|---|---|
| 1. Start the sound | `start()` | Asks for the microphone, with echo cancellation and noise suppression turned **off** so the raw sound comes through. Creates a steady sine-wave tone (an *oscillator*) and plays it through the speaker. |
| 2. Pick the best tone | `calibrate()` | Tries frequencies from 16.6 to 20 kHz and keeps the one the phone's mic hears most clearly. Every phone's speaker and mic are a little different. |
| 3. Turn sound into a moving point | `onAudio()` | Runs about 12 times a second on chunks of microphone sound. Multiplies the sound by a cosine and a sine at exactly the tone's frequency, then averages over 100 ms. This is **I/Q demodulation**: what's left is a point (I, Q) that holds the echo's strength and its *phase* (how far the sound traveled). |
| 4. Store it | `pushSlow()` | Saves each (I, Q) point, 10 per second, in a 4-minute ring buffer, then calls the checks below on a schedule. |
| 5. Points to chest motion | `displacement()` | When the chest moves, the echo's phase changes, so the (I, Q) point moves along an arc. Echo fits a circle to that arc (the angle around the circle is the chest's distance), and also tries the main direction the points move in (PCA). It keeps whichever shows a clearer rhythm. Moving 1 mm changes the phase a measurable amount, because the sound's wavelength is only about 2 cm. |
| 6. Remove slow drift | `removeDrift()` | Subtracts a 10-second moving average, so slow changes (the phone warming up, the body settling) don't look like breathing. |
| 7. Breathing rate | `estimateRate()` | A Fourier analysis (DFT) of the last ~28 seconds finds the strongest rhythm between 5 and 36 breaths per minute. |
| 8. Steady number on screen | `updateRate()` | Shows the **median** (middle value) of the last 20 seconds of readings, so one bad reading can't make the number jump. Readings far from it, or under 8/min, stay out of the night's average. |
| 9. Is breathing clearly visible? | `bandSNR()`, `rhythmScore()`, `motionRhythm()` | `bandSNR` compares motion at breathing speeds (0.1–0.7 Hz) with fast jitter (1.5–4.5 Hz). `rhythmScore` checks how much the rate peak stands out. `motionRhythm` checks that the motion repeats every 2–8 seconds (autocorrelation) and is 4+ times bigger than the jitter. |
| 10. The decision, once a second | `checkBreathing()` | Combines everything into a state: **seeing** (record), **pause** (log it), or **lost** (record nothing, don't guess). The thresholds are constants at the top of the engine: `BAND_MIN = 50`, `CLAR_MIN = 6`, `SNR_MIN = 12`, `PM_MIN = 12`, `ENTER_SEC = 8`, `PAUSE_AFTER_SEC = 20`. |
| 11. Breaths and pauses | `detectBreaths()` | Finds each breath (peaks and troughs) in the motion. If none for 10 s after 20+ s of clear breathing, with no big movement first, that's a pause. |
| 12. Quiet-chest pauses | `quietPause()` | The second way to catch a held breath: the chest motion over the last 8 s drops below 40% of the breathing before it. It refuses if the breathing before wasn't clear, if there was a jolt (rolling over, bumping the phone), or if breathing doesn't come back within 60 s. Constants: `Q_RATIO`, `Q_JIT_LO/HI`, `Q_DEEP`, `Q_TAPER`. |
| 13. Breathing pattern | `analyzePattern()`, `updatePattern()` | Measures how regular the breaths are, and looks for waxing-and-waning (breaths that grow, shrink, then pause in a repeating cycle). It only counts when breathing was seen 80% of the time, and must last 5 minutes in total. |

## Extra checks while listening

| Function | What it does |
|---|---|
| `checkSnore()` | *(experimental)* Twice a second, measures loud low sound (80–800 Hz). Snoring = regular bursts 10 dB above the room's quiet level. |
| `trackOutOfBed()` | *(experimental)* After clear breathing, 90 s with almost no breathing motion counts as "out of bed or out of view". |
| `updateAim()` | The aim check in the first 90 s: Good / Okay / Too weak. |
| `drawIQ()`, `drawSpec()` | The Science view: the live (I, Q) arc and the breathing spectrum. |

## Saving nights and reports

| Function | What it does |
|---|---|
| `beginWatching()` | Resets everything when a night starts. |
| `buildEntry()`, `saveSession()` | Packs the night (rate every 30 s, pauses, what was seen, snoring) and saves it in the phone's browser storage (`localStorage`). |
| `autosave()`, `recoverNight()` | Saves progress every 30 s, and recovers the night if the battery dies or the page closes. |
| `finishSession()` | Works out averages and percentages for a saved night. |
| `renderReports()` | Draws the Reports tab: summary sentence (`summarySentence()`), confidence badge (`confidenceOf()`), timeline, charts, details. |
| `scResult()`, `sleepCheckHTML()`, `docHTML()` | The Sleep Check: combines the last 3 good nights with the 6 NHLBI questions into a next step, and builds the doctor summary. |
| `tagCardHTML()`, `effectsHTML()` | Night tags, and the "What affects breathing" comparison on the Trends tab. |
| `renderTrends()`, `compareToNormal()` | Learns the person's normal breathing rate and flags nights 3+ above it. |
| `sendFamily()` | Texts the family contact a short summary. |

## Words worth knowing

- **Carrier / tone:** the steady high sound Echo plays (about 16.6–17 kHz).
- **I/Q demodulation:** multiplying the received sound by a cosine and a sine of the tone, which turns it into a slowly moving point. Its angle (phase) tracks distance.
- **Phase:** where in its wave cycle the echo arrives. A tiny change in distance makes a measurable change in phase.
- **DFT / Fourier analysis:** finding which rhythms (frequencies) a signal contains. The strongest one in the breathing range is the breathing rate.
- **Autocorrelation:** comparing a signal with a delayed copy of itself. If it matches well at some delay, the signal repeats with that period.
- **Median:** the middle value of a sorted list. It ignores outliers better than the average does.
- **PCA (principal component analysis):** finding the main direction the points move in.
